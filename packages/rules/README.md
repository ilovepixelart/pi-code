# pi-code-rules

Replicates Claude Code's rules loading: global `~/.claude/rules/*.md` are inlined in full into the system prompt, project `.claude/rules/*.md` are listed as pointers the agent reads on demand.

Adapted from the `@earendil-works/pi-coding-agent` v0.74.2 `claude-rules` example (MIT), maintained here for full control.

## Install

```bash
pi install git:github.com/ilovepixelart/pi-code-rules
```
