# Statusline

Runs a configured Claude `statusLine` command. Source: [`extensions/status-line.ts`](../extensions/status-line.ts).

- The stdin JSON follows Claude's contract, with two fields it no longer lists (`hook_event_name`, sent as `Status`, and `permission_mode`) kept for scripts written against the older shape, and several it now lists that pi has no source for (`workspace.repo.*`, `worktree.*`, `pr.*`, `prompt_id`, `agent.name`, `vim.mode`): `version`, `hook_event_name`, `session_name`, a `cost` block with wall and API durations and lines added/removed, a `context_window` token breakdown, `exceeds_200k_tokens`, `workspace.added_dirs` from the `--add-dir` flag (empty when none were given), `workspace.git_worktree`, `effort` in Claude's vocabulary (pi's `minimal` maps to `low`, `off` omits it), and `rate_limits` carrying the `five_hour`/`seven_day` utilization with `resets_at` as Unix epoch seconds; an expired window is dropped rather than left stale. `fast_mode`, `prompt_cache`, and `spend_limit` have no pi source and stay absent.
- Scripts run with `CLAUDECODE=1`, `CLAUDE_CODE_CHILD_SESSION=1`, and `COLUMNS`/`LINES` set to the terminal dimensions.
- `padding` and `refreshInterval` are honored, with a 300ms debounce. A change to the `command` itself skips the debounce and runs at once, since there is nothing to batch it with. Re-run triggers otherwise follow Claude, minus the two pi cannot source (a vim-mode toggle, and a warm prompt cache reaching its threshold).
- **A script may print several lines**, as Claude documents, and every line reaches the display. pi renders all extension statuses on one row and replaces newlines with spaces before drawing it, so the lines are joined by a space and the row is truncated to the terminal width. Blank lines are dropped rather than rendered as gaps.
- **Not implemented, and not implementable here:** `subagentStatusLine` (Claude draws one script-provided row per subagent in an agent panel; pi's only status surface is a single keyed footer string) and `hideVimModeIndicator` with the `vim.mode` payload field (pi has no vim mode to report).
- Without a configured command, a built-in statusline shows turn state and session cost.
